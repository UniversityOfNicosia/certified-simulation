# Code of Conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Participation in this repository's issues and
discussions is expected to follow it.

Instances of unacceptable behavior may be reported to the repository
maintainers through GitHub (a private report via the repository's
Security tab reaches the maintainers directly). All reports will be
reviewed and handled with discretion.
